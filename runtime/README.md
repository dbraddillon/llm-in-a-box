# LLM in a Box

Double-click `launch.cmd` (Windows) or run `./launch.sh` (Mac/Linux) to start it.
Then open http://127.0.0.1:7860 in your browser.

Ask it questions about the content that was loaded onto this drive. It only knows
what's in the `index/` folder here — nothing else — and it needs no internet
connection to run.
